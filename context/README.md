# AI Agent resources

Agent context packs for use with Knowledge Discovery (IDOL) components.

Each context pack is a directory holding a set of resource files giving AI
agents context around using a Knowledge Discovery component. 

## Using them

Drop all the items above into whatever context mechanism the tool offers -
a project in Claude / ChatGPT, a `repomix` bundle, a Cursor workspace, or the
working tree a command-line coding agent is pointed at, then ask the agent
for what you want.
