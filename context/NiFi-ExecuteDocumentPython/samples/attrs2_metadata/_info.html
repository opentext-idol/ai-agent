The FlowFileDocument XML metadata is a block of XML that is usually stored as a FlowFile attribute 'idol.xmlmetadata'.

For large XML metadata, it may instead be stored as a special embedded XML part of the FlowFile content. In this case the FlowFile attribute 'idol.xmlmetadata.embed' will be set to 'true'.

The following methods can be used to read and write the XML metadata:

  • with FlowFileDocument.getXmlMetadata() as xml
  • xmlstr = FlowFileDocument.getXmlMetadataString()

  • FileAction.setXmlMetadataString(xmlstr)
  • FileAction.clearXmlMetadata()

  • xml = DocumentAction.getXmlMetadata()

When iterating over document parts, the following method can be used to get access to the part XML metadata
(The <part id="[PartId]"/> elements directly below the XML metadata root):

  • xml = DocumentPartAction.getPartXmlMetadata()
  • for xml in DocumentAction.getXmlMetadata().getElementsByXPath("part[@id='{0}']".format(part.getPartId()))
