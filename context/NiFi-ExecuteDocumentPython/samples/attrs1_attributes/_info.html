The FlowFileDocument provides access to all the FlowFile attribute, and provides access to special attributes like idol.reference and idol.xmlmetadata, as well as any custom attributes. Attributes may also be attached to document parts, and are assigned as FlowFile attributes named 'idol.doc.part.[PartId].[PartAttributeName]'.

Most attributes may be read and written directly from a FlowFileDocument. Part attributes are specifically excluded as these should be accessed through part operations using DocumentPartAction. There are specific accessor methods for special attributes like idol.reference and idol.xmlmetadata.

The following methods can be used to read and write the FlowFile attributes:

  • value = FlowFileDocument.getAttribute(name)
  • FlowFileDocument.setAttribute(name, value)
  • FlowFileDocument.removeAttribute(name)

  • value = DocumentAction.getAttribute(name)
  • DocumentAction.setAttribute(name, value)
  • DocumentAction.removeAttribute(name)

  • value = DocumentPartAction.getPartAttribute(name)
  • DocumentPartAction.setPartAttribute(name, value)
  • DocumentPartAction.removePartAttribute(name)
