File parts of a FlowFileDocument are segments of a FlowFile containing binary data or references to externally stored files.

There are three types of file part:

  • Embedded files, accessed via DocumentAction.isEmbeddedFilePart() and ContentFileAction
  • Filenames referencing files on the filesystem, accessed via DocumentAction.isFilenamePart() and ContentFilenameAction
  • External files referencing files in external storage, accessed via DocumentAction.isExternalFilePart() and ExternalFileAction

The following methods can be used to read and write file parts of any type:

  • with FileAction.readAsFilename() as tmpfilename
  • with FileAction.readFile() as inputstream

  • FileAction.transferToFile(...)
  • FileAction.transferToFilename(...)
  • FileAction.transferToExternalFile(...)

  • FileAction.transformAsFilename(...)
  • with FileAction.transformFile() as (inputstream,outputstream)

The display filename and the file mime-type can be set using the following methods on any file part:

  • FilePartAction.setFileDisplayName(...)
  • FilePartAction.setFileMimeType(...)

The subclasses of FileAction provide additional operations for the specific file part types.
