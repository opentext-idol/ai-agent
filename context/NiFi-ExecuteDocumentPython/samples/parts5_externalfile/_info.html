External file parts of a FlowFileDocument are segments of a FlowFile containing the details to access a file in external storage. The external file may be owned by the part, meaning that it would be deleted when the part is deleted. An IdolFlowFileService can be used to manage the storage details used by the parts via a Service Key string.

The following methods can be used to read and write external file parts in addition to the inherited operations from FileAction:

  • owned = ExternalFileAction.hasOwnership()
  • ExternalFileAction.disownFile()
  • fileexists = ExternalFileAction.exists()
  • url = ExternalFileAction.getDownloadUrl()

  • locator = ExternalFileAction.getLocator()
  • ExternalFileAction.replaceLocator(...)
