The 'Overwriting' context allows access to any part of the FlowFileDocument for reading. All existing parts are discarded but can be explicitly rewritten or transformed or new parts added.

An 'Overwriting' context can be started with one of the following methods:

  • FlowFileDocument.overwrite(...)
  • for parts in FlowFileDocument.partsOvewrite()
  • with FlowFileDocument.overwriting() as action
