Filename parts of a FlowFileDocument are segments of a FlowFile containing the path of a file on the filesystem. The file may be owned by the part, meaning that it would be deleted when the part is deleted.

The following methods can be used to read and write filename parts in addition to the inherited operations from FileAction:

  • owned = ContentFilenameAction.hasOwnership()
  • ContentFilenameAction.disownFile()
  • fileexists = ContentFilenameAction.exists()
  • filename = ContentFilenameAction.getFilename()

  • with ContentFilenameAction.readFile() as inputstream
  • ContentFilenameAction.replaceFilename(...)
