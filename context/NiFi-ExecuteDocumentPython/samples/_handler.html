The processor is configured with a "Python script function" property. This defines the name of the function that will be called from the main script.

The default defines the function name as "handler". The main script (defined by the property "Python script file") should include a definition for the handler function. def handler()

The function may be declared as having any of the following argument names, which will be assigned the appropriate object based on the names.

Argument name         Type of object assigned
p idolnifi.Processor
processor
c idolnifi.ProcessContext
context
s idolnifi.ProcessSession
session
ff idolnifi.FlowFile (*)
flowfile
doc idolnifi.FlowFileDocument (*)
ffdoc
document
flowfiledocument

* If the processor does not have an input connection, the handler cannot accept a FlowFile or FlowFileDocument as an argument. FlowFiles and FlowFileDocuments can still be created by the processor as output. When an input connection is present, only one of FlowFile or FlowFileDocument is allowed as an argument to the function.
