The 'UpdatingAttributes' context allows access to any part of the FlowFileDocument for reading, and also for modifying attributes and XML metadata. Other write operations will fail.

An 'UpdatingAttributes' context can be started with one of the following methods:

  • FlowFileDocument.updateAttributes(...)
  • for parts in FlowFileDocument.partsUpdateAttributes()
  • with FlowFileDocument.updatingAttributes() as action
