A file_map block is a flat set of key → filename entries. A csv_file refers to a key through its file_key, so the data file can be relocated or replaced without editing the data source or the lookups.

At most one file_map block is allowed per configuration file, but its keys are global - merged across every loaded file, and a duplicate key anywhere is an error. A relative filename resolves against the configuration file's own directory, and must stay within a configured directory.

In the Blocks tab, each file_map entry has upload and download controls: upload replaces the data file (stored gzip-compressed in the managed directory), and download retrieves the stored copy. Gzip-compressed source files (.gz) are read transparently.
