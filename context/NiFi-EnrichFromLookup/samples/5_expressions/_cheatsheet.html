NiFi Expression Language is available in csv_file.names expressions (where attributes are the raw CSV column values), lookup.inputs (attributes are the document field values), and lookup.outputs (attributes are the matched data row's column values). Dynamic processor properties are available everywhere as ${property:Name}.

Goal Expression
Pass a value through unchanged ${postcode}
Strip a ZIP+4 suffix ${postcode:replaceAll('-.*', '')}
Remove spaces ${postcode:replace(' ', '')}
Normalise to upper case ${country:toUpper()}
First five characters ${postcode:substring(0, 5)}
Constant value (no source field) ${literal('US')}
Concatenate several columns ${literal('${place}, ${region}, ${country}')}
Trim leading / dangling separators ...:replaceAll('^(, )+|(, )+(?=, |$)', '')
WKT geo-point ${literal('POINT(${longitude} ${latitude})')}
Read a dynamic property ${property:default_country}

The literal('...') wrapper lets you embed several ${column} references inside one string before applying further functions to the whole result - the basis of the concatenation and geo-point patterns above.
